# 🎙️ Aira - Offline AI Voice Assistant

![License](https://img.shields.io/badge/license-MIT-blue)
![Platform](https://img.shields.io/badge/platform-Android-brightgreen)
![Android](https://img.shields.io/badge/Android-6.0+-green)

A powerful **offline-first AI voice assistant** for Android with an immersive Iron Man-style HUD interface. Talk naturally, get intelligent responses—even without internet.

---

## ✨ Key Features

- **🧠 Intelligent AI Brain**  
  Conversational AI powered by Groq (Llama) and Google Gemini with offline fallback caching

- **🔊 Offline Speech**  
  Built-in text-to-speech using Piper/Vosk—works anywhere, no internet needed

- **🎨 Futuristic HUD UI**  
  Sleek Iron Man-inspired interface with smooth animations and modern design

- **🌓 Dynamic Themes**  
  Switch between light/dark modes with customizable accent colors

- **⚙️ Smart Controls**  
  Manage volume, brightness, Bluetooth, and more directly from the app

- **🛡️ Reliable & Stable**  
  Global error handling with instant user feedback

---

## 📋 Technical Details

| Component | Technology |
|-----------|-----------|
| **UI Framework** | Jetpack Compose (Kotlin) + Material 3 |
| **Architecture** | MVVM |
| **Local Storage** | Room Database |
| **Networking** | OkHttp with custom interceptors |
| **Speech** | Native Android SpeechRecognizer & TextToSpeech |

## 🚀 Getting Started

### Requirements
- **Android 6.0** or higher
- **150 MB** free storage

### Installation

1. **Download APK**  
   Get the latest release from the [Releases](https://github.com/USER/REPO/releases) page

2. **Install**  
   - On your Android device, enable "Install from Unknown Sources" in Settings
   - Open the APK file and tap **Install**

3. **Configure API Keys** (Optional)  
   - For best performance, add your Gemini/Groq API keys in app settings
   - Works offline without keys (uses cached responses)

### Build from Source

```bash
# Clone repository
git clone https://github.com/USER/REPO.git
cd REPO

# Open in Android Studio
# Sync Gradle files
# Add your API keys to local.properties (optional)
# Build & Run
```
